# Project continuity

`python studio.py new NAME` creates a clean project. Its fields are empty, not inherited from examples. Record competition/round/prompt, guidebook/version, rubric, deadline/timezone, counted pages, format, current task and protected scope.

Maintain venture definition (customer, payer, offer, transaction, revenue, delivery, first market and expansion), decisions with accepted/exploring/rejected/superseded/protected status, canonical numbers with unit/period/formula/source, evidence states, assumptions and sensitivity, latest artifacts, sources with physical page locators, open issues, actual checks and next action. Selecting a design does not turn its assumptions into observed results.

Update after material changes. Preserve the last accepted version. Label older exports historical. A wording revision need not rebuild unchanged economics; a price change must regenerate dependent tables, figures and prose.

Run `python studio.py handoff NAME` to emit a readable handoff from `project-record.json`. Attach that record, latest files and actual guidebook to a new session. Recover current facts before proposing changes. No handoff implies memory of unseen chats.
