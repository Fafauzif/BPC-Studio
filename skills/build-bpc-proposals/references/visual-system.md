# Visual system

Study the [reference atlas](../../../docs/reference-atlas.md), thirteen supplied image references and [existing chart gallery](../../../docs/chart-gallery.md) before adding chart families. ReFeel locates a service at one purchase decision, gives two participant groups different incentives and aligns market nesting with calculations. Dua connects dimensioned product views to use, compares a credible substitute fairly and joins schedule with owners, indicators and responses. Transfer these relationships and geometry; keep source brands, numbers, research and achievements with the originals.

## Choose the exhibit's job

| Question | Existing family | Interpretation boundary |
|---|---|---|
| Where does the service change a decision? | service_flow | Six stages only when the operation really fits |
| Why does a problem persist? | issue_tree | Supported leaves; geometry is not causal proof |
| Who reports or decides? | structure_tree | Owned and funded work, not decorative titles |
| What do two sides receive? | value_proposition | Concrete jobs, pains, gains and functions |
| Which market is included? | tam_sam_som | Schematic circles, not area-proportional values |
| What differs under equal scope? | bar_comparison | Same denominator, units and zero baseline |
| When is cash tight? | cash_line | Model series; funding is not profit |
| What happens when? | gantt | Exact schedules remain native Word tables |
| What deserves risk attention? | risk_heatmap | Ordinal ratings, not calibrated success probabilities |
| How do alternatives compare? | positioning | Supported axes and disclosed judgment |
| How do supplied draws vary? | distribution | Conditional draws, not empirical market evidence |
| Which inputs covary with output? | drivers | Computed association, not causal effect |

The prose makes the consequential claim; the figure reveals a relationship; a native table preserves exact values. Use one visual question per exhibit, a restrained project-selected palette, high contrast and consistent meaning for fills and lines. White space separates groups. Arrows carry direction/responsibility rather than decoration. Do not import an old palette or watermark into a new venture.

## Editable chain and placement

Retain input JSON/data, editable TeX, vector PDF, placement PNG and compile metadata together. Run `studio.py chart SPEC.json --out-dir PROJECT/assets/charts`. Labels are escaped and shell escape is disabled. Inspect untrusted downloaded TeX before execution; a reference archive is for learning, not automatic code execution.

Derive financial/chart series from canonical calculations. Do not retype convenient rounded values or invent simulations for decoration. State units, period and observation/forecast basis. Explain schematic market geometry in the caption. Do not distort an operation into six stages merely to fit a template; use a native table or an adapted editable diagram.

Choose document width before compilation. Inspect chart metadata's actual PDF text sizes after scaling, then inspect the figure in the rendered document at ordinary page size. Long labels need wider boxes, fewer nodes or a split exhibit, not microtype. A large PNG can still be unreadable at 7 cm. Check labels, arrows, decimals, legends, zero baselines, glyphs and clipping. Keep caption/image together without binding an entire long appendix.

Concept imagery explains intended form. Actual screenshots show captured software states. Precise charts and schedules use data-driven tools. Never generate a fake screenshot, certificate or numerical evidence. A binary inventory or TeX source is not a compiled chart; a compilation pass is not a visual or economic pass.
