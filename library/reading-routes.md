# Reading routes

Start with the current user task, latest accepted project record and actual competition guidebook. Then read the active BPC manual. Read commercial-writing.md for prose and the task-specific module. Historical manuals do not control the task.

For a narrow revision, select a lesson or two with the matching problem. Open the original when its actual passage, exhibit or arithmetic matters. Never claim a fresh complete source read from an index. The initial build coverage records describe this release's reading, not every future agent's reading.

| Need | Route |
|---|---|
| Complete written proposal | BPC manual → architecture → commercial writing → relevant lessons |
| Product modules and production/QC | Dua study and source, especially product, production and specifications |
| Multi-party service, payer and revenue event | ReFeel study and source, especially customer decision and service workflow |
| Commercial prose and transitions | Commercial writing → essay craft synthesis → selected original essay |
| Business-plan conventions and weaknesses | BPC synthesis → specific BPC-xx lessons → original PDF |
| BMC only | Supporting formats → selected Contoh BMC lessons, not all proposals |
| Exact chart geometry | Visual system → chart gallery → reference atlas → actual image/source |
| Financial credibility | Finance → model inputs/results → source-specific arithmetic lessons |
| Case reproduction | cases/jejakbalik inputs and its historical README; never inherit facts into a new venture |

Transfer information relationships, argument development and inspectable structure. Rebuild facts, calculations, names, approvals and achievements for the current business. Repeated source wording counts as correlated craft evidence; overlap is recorded without claims about authorship.
